## 📌 Executive Summary

This repository presents a full **homepage clone and creative redesign** built for **Dr. Maya Reynolds, PsyD**, a licensed clinical psychologist in **Santa Monica, California**. 

The application preserves the layout structure and hierarchy of the reference website ([Conejo Valley Counseling](https://www.conejovalleycounseling.com/home)) while delivering a elevated, design-forward experience with rewritten copy, custom images, local SEO optimization, and a new custom **"Our Office"** section.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Open in browser
# Navigate to http://localhost:3000
```

To build for production verification:
```bash
npm run build
```

## 📦 Deployment Instructions (Vercel / Netlify)

1. Push this repository to GitHub.
2. Import the project into **Vercel** or **Netlify**.
3. Select Framework Preset: `Next.js`.
4. Deploy — zero environment variables needed!
