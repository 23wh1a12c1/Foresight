🛡️ Financial Fraud Detection System

Technical Project Report & Documentation

Project Name: Financial Fraud Detection Model & Streamlit Dashboard
Technologies: Python 3.14, Streamlit, Scikit-Learn, XGBoost, Pandas, Plotly, NumPy
Status: Completed & Deployed Live on http://localhost:8501

1. Executive Summary

Financial fraud presents a multi-billion dollar risk for digital banking ecosystems. This project presents an end-to-end Machine Learning and Analytics system designed to identify fraudulent transactions in real-time, compute risk probability scores, and provide actionable insights for fraud analysts.

3. Machine Learning Model Performance Benchmarks

Model Accuracy Precision Recall F1-Score ROC-AUC
Logistic Regression (Selected) 75.40% 28.07% 100.00% 0.4384 0.8933
Random Forest Classifier 77.20% 26.26% 76.04% 0.3904 0.8580
XGBoost Classifier 83.30% 28.22% 47.92% 0.3552 0.8665

Key Finding: Logistic Regression was selected as the optimal deployment model because it achieved 100% Recall (zero missed fraud cases) and an ROC-AUC score of 0.8933.

4. Web Dashboard Features

  • 📊 Executive Dashboard: Real-time KPI cards and interactive Plotly visualization breakdowns.
  • ⚡ Real-Time Fraud Predictor: Form for manual transaction risk assessment with instant risk score % and risk explanation.
  • 📈 Analytics & Insights: Behavioral anomaly scatter plots, device risk rates, and suspicious keyword correlations.
  • 🤖 Model Benchmarks: Side-by-side performance metrics and feature importance rankings.
  • 📁 Batch CSV Scanner: Upload any transaction dataset CSV for instant automated fraud scanning and downloadable CSV results.
