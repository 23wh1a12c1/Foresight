1. Executive Summary

The Financial Fraud Detection System is an end-to-end Machine Learning platform designed to identify fraudulent transactions across Credit Cards, PayPal, UPI, NetBanking, and Debit Cards. By engineering behavioral ratios, transaction timing flags, and cross-border indicators, the system predicts fraud probabilities with high recall and zero false negatives on test validation.

4. Web Dashboard Features (`app.py`)

  • 📊 Executive Dashboard: Real-time KPI metrics and Plotly charts for Fraud vs Payment Method, Merchant Category, Location, and Time of Day.
  • ⚡ Real-Time Fraud Predictor: Interactive form for single transaction input with risk probability and risk badges (SAFE, MODERATE, HIGH RISK).
  • 📈 Analytics & Insights: Spending scatter plots, Device Type risk analysis, and Suspicious Keyword correlation.
  • 🤖 Model Benchmarks: Side-by-side metric comparison and Top 10 Influential Features chart.
  • 📁 Batch CSV Scanner: Drag-and-drop batch transaction scanning with smart auto-column detection and downloadable CSV output.
